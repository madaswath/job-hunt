# Job-hunt

India-focused, candidate-controlled job-search copilot. Phase 1 is live: Clerk-ready Vite workspace, FastAPI modular monolith, fixture ATS discovery, Arjuna Match v2, review inbox, and a Python worker with leases/outbox.

The product never auto-submits applications or sends messages. Later agents and marketplace connectors are catalog/planned until they have executable code and passing tests.
